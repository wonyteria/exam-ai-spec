# Mathematics Guide
ExamDNA Core 위에 중학교 수학 전용 복원·검증 규칙을 제공한다.

## 책임
Math OCR/AST, 단위·기호 처리, 도형 구조, 문제 풀이, 정답 검증, 학년 수준 해설.

## 검증 순서
```text
Text Verify
→ MathGuard
→ FigureDNA
→ QuestionLogic Guard
→ Solver Verification
→ Curriculum Guard
```

## 원칙
- 문제 원문 그대로
- 수식 구조 보존
- 도형 topology/relation 보존
- 학생 추가선 제거
- 학년 수준을 넘는 해설 금지
