## 공개 정보에서 드러난 제약과 위험

- 설치형 Windows 프로그램과 별도 문제은행 사이트로 경험이 분리된다.
- AI 기능 사용자가 외부 API 계정을 만들고 키를 등록해야 한다.
- 업데이트 내역에 수식 깨짐, 긴 수식 줄바꿈, 도형·축 레이블 누락, 잘못된 크롭, 표 안 수식, 단위 로만체, 복잡 페이지 누락이 반복된다.
- 일부 실패는 빠른/정밀 모드 선택이나 수동 영역 지정으로 사용자에게 복구 책임이 이동한다.
- 공개 영역에서는 여러 학원의 tenant 격리, 역할 권한, 감사 로그, 보관·삭제·복구, 산출물 proof를 확인할 수 없다.

## ExamAI Spec에 반영할 경쟁 요구

1. 교사는 웹만 사용하고 AI 키·Windows COM·모델 설정을 다루지 않는다.
2. 중앙 Windows worker가 HWPX 열기, HWP 저장, 재열기, PDF 저장과 artifact hash를 proof로 남긴다.
3. 속도 중심/정밀 모드를 단순 선택지로 두기보다 입력 위험도와 검증 결과로 자동 승격하고, 품질이 부족하면 다운로드를 차단한다.
4. 원본 crop과 canonical 값을 항상 연결하고 수식·도형·표·축·레이블·단위 스타일을 자동 대조한다.
5. 자동 복구가 불가능할 때만 source 비교·도형 보정·typed resolution을 제공하며 수정 이력과 undo/redo를 남긴다.
6. 학원별 역할·문서·원본·crop·revision·artifact를 격리하고 교차 접근을 테스트한다.
7. 페이지/문항별 예상 비용, 실제 사용량, 재시도 비용, quota와 대기 시간을 학원 관리자에게 제공한다.
8. 오류 신고에는 원본 좌표, revision, renderer/provider 버전, proof hash를 자동 첨부해 재현 가능하게 한다.
9. HWP/PDF/학생용/교사용의 의미를 분리하고 학생용 답안 노출을 자동 검사한다.
10. 공개 업데이트 내역처럼 결함 유형을 숨기지 않되, 출시 게이트에서는 미검증 항목을 PASS로 계산하지 않는다.

이 문서는 공개 기능을 참고한 경쟁 분석이며 화면·문구·가격 정책을 복제하기 위한 명세가 아니다.
