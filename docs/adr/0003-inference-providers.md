# ADR-0003: 추론 프로바이더 프로필

상태: 설계 고정, 실제 유료 호출은 승인·예산 확정까지 mock/cache-only(RG-03)
날짜: 2026-09-19

## 결정

- 운영 기본 프로파일은 **OpenAI Responses 서버 어댑터**다. 후보 모델 `gpt-5.6-luna`(추출/구조화)와 `gpt-5.6-terra`(독립 검증/풀이)는 미검증 후보이며, 실제 모델명·단가는 RG-03 승인 시 확정한다.
- **Gemini는 운영 기본 구성과 자동 폴백에서 제외**한다. 코드에 남아 있는 Gemini 경로는 dev/테스트 전용 capability로 격리하고, 프로덕션 프로파일에서는 등록하지 않는다.
- **Codex(개발 구독)는 개발·QA 전용**이며 운영 추론 계정으로 사용하지 않는다. 개인 토큰·`auth.json`·브라우저 세션은 저장소·로그·서버에 복사하지 않는다.
- 유료 프로바이더 자동 승격·자동 폴백을 하지 않는다. 프로바이더 변경은 명시적 운영 결정이다.
- 두 번의 독립 풀이는 서로 다른 실행 경로(별도 호출·별도 seed/prompt 변형)로 수행하며, 같은 캐시 두 번 읽기는 독립 검증으로 인정하지 않는다.

## 근거

- 06_AI_COST_AND_OPERATIONS.md의 기본 운영안과 일치한다.
- Gemini SDK는 현 개발 환경에도 미설치였고, replay 테스트는 SDK 없이 동작해야 한다(ADR-0006).
- 예산 미승인 상태에서 실제 API 호출 경로를 열어두면 비용·데이터 전송 통제가 깨진다.

## 영향

- `backend/providers/`에 `ProviderProfile` 개념 도입: `openai_server`(운영 기본, 키 없으면 비활성), `gemini_dev`(격리), `replay_cache`(테스트 전용), `mock`(테스트 전용).
- offline CI는 네트워크 호출 0을 강제한다 — provider 레이어에 outbound 차단 훅을 두고 테스트에서 검증.
